# Dirección: mesa editorial impresa

Propósito: comparar evidencia, inspeccionar acontecimientos y registrar decisiones.
Tono editorial/utilitario. Ancla: masthead con marca radar, títulos serif y tablas de atención.
DFII: impacto 4 + contexto 5 + viabilidad 5 + rendimiento 5 − riesgo 4 = 15.
Paleta papel, tinta verde profunda y acento terracota. Tipografía Georgia para titulares y
Trebuchet MS para controles; fuentes locales, sin requests externos. Ritmo de 8 px.
Sin animaciones decorativas. Tablas accesibles, foco visible, navegación móvil horizontal.
Comparaciones mediante SVG accesible y tablas semánticas. El frontend usa Fetch nativo
en lugar de HTMX/Chart.js, sin dependencias externas durante el uso local.
