# Changelog

## 0.1.0 — 2026-10-15

Primera implementación ejecutable de Agenda Radar a partir de las especificaciones aprobadas.
Persistencia local trazable, ingesta, agrupamiento revisable, comparación de agendas, configuración
versionada, roles, consultas estructuradas, alertas Telegram y recuperación operativa.

La entrega incluye pruebas, scripts, empaquetado y documentación. La aceptación del piloto
continúa pendiente; ver STATUS.md para resultados y límites específicos.
